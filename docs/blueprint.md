# **App Name**: NextMatrix

## Core Features:

- Interactive Roadmap: Interactive roadmap display with collapsible sections for each phase and topic.
- Embedded Code Playgrounds: Embedded mini-playgrounds (like StackBlitz or CodeSandbox) for each topic, allowing users to run and experiment with code examples directly within the learning environment.
- Animated Flashcards: Animated flashcards for quick review, featuring a question on the front and the answer on the back.  Users can mark cards for later review.
- Interactive Quizzes: Interactive quizzes and exams with multiple-choice questions and code completion challenges, providing instant feedback and scoring.
- Markdown Notes Editor: Obsidian-style Markdown editor with live preview, backlink support, tag management, and code block formatting.
- Progress Dashboard: Dashboard that visually displays progress per phase and topic, lists completed vs. pending topics, and tracks quiz scores.

## Style Guidelines:

- Primary color: Neon green (#39FF14), inspired by the Matrix's digital rain, providing a vibrant and tech-forward feel.
- Background color: Dark grey (#222222) to provide a strong contrast, creating a digital canvas reminiscent of a computer terminal.
- Accent color: Electric blue (#7DF9FF), analogous to green and offering contrast to guide focus and highlight interactive elements.
- Body and headline font: 'Space Grotesk', a sans-serif font lending a modern, computerized feel.
- Code font: 'Source Code Pro' for code snippets, perfect for instructional materials.
- Modular design with clear separation of sections, ensuring ease of navigation.
- Subtle animations for transitions and interactions, mimicking a terminal interface.
